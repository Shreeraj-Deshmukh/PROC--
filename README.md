# PROC--
Proc++ transpiler and preprocessor for fun. feel free to add more mappings which relate to procdna terminologies. 

INSTRUCTIONS TO RUN

-------------------
1 } compile the transpiler file firtly, g++ transpiler.cpp -o transpiler.exe
works on g++ 14 only , not on g++17
This has to be done only once, as long as the terminal isnt closed or the executable file is not deleted

2 } Create any file with the .proc++ extension. for example, the file is hello.proc++, 
then run ./transpiler.exe hello.proc++
for powershell bezoz lovers, run .\transpiler.exe hello.proc++


debug using claude code.
